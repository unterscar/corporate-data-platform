# Corporate Data Platform
Учебный проект по дисциплине
«Современные технологии разработки программного обеспечения».

## Цель проекта – создание корпоративной программной платформы для обработки, хранения и анализа данных.

## Назначение платформы
Платформа предназначена для получения, хранения, обработки и анализа корпоративных данных.
В рамках проекта будут последовательно реализованы контейнеризация, автоматизация обработки данных, аналитика и мониторинг.

## Планируемые компоненты
- Git
- Docker
- Docker Compose
- Kubernetes
- CI/CD
- Apache Airflow
- MinIO
- DuckDB
- NetworkX
- Grafana
